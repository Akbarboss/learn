# Тест по локальной сети

Запускается на вашем компьютере и раздаёт тест на телефоны в той же
Wi-Fi сети. **Брату не нужен ни аккаунт Claude, ни приложение, ни
установка** — он просто открывает ссылку в браузере.

```bash
python exam-server.py
```

Сервер напечатает адрес вида `http://192.168.1.14:8765` — его и открываете
на телефоне.

---

## Чем это отличается от теста-артефакта

| | Артефакт на claude.ai | Этот сервер |
|---|---|---|
| Нужен аккаунт Claude | да, каждому | **нет** |
| Кто платит за проверку | тот, кто отвечает | вы, по API-ключу |
| Отмеченные слова | вставлять кодом вручную | **берутся сами из Firebase** |
| Где результаты | скопировать и прислать | **сохраняются у вас** |
| Нужен интернет у брата | да | нет, хватает вашей сети |

У сервера есть сеть, поэтому он сам читает, какие слова человек отметил
выученными, — копировать код между страницами больше не нужно.

---

## Кто проверяет ответы

Сервер пробует три вещи по порядку и берёт первое, что доступно.

### 1. Claude Code — рекомендуется, ключ не нужен

Тратится подписка, за которую вы уже платите. Установка:

```bash
npm install -g @anthropic-ai/claude-code
```

Затем **один раз** войти — у командной строки свой вход, от десктопного
приложения он не наследуется:

```bash
claude
```

внутри набрать `/login`, пройти вход в браузере, выйти. После этого
перезапустить сервер — он сам найдёт CLI и будет спрашивать его.

Если вход не сделан, сервер об этом прямо напишет при первой же проверке
и дальше будет откладывать спорные ответы.

### 2. API-ключ — если CLI по какой-то причине не подходит

Берётся на **console.anthropic.com**, оплачивается отдельно по расходу
(доли цента за проверку). Положить можно так:

```bash
set ANTHROPIC_API_KEY=sk-ant-...
```

или файлом `api-key.txt` рядом с `exam-server.py`.

Файл `api-key.txt` и папка `results/` в `.gitignore` — на GitHub не
попадут. Ключ не отправляется на телефон и не пишется в результаты.

### 3. Без того и другого — тоже работает

Ответы сверяются со словарём. Всё, что словарь не смог засчитать,
**не помечается неверным** — откладывается и ждёт вас на странице
результатов в разделе «Needs your eye». Правильный синоним не будет
объявлен ошибкой.

Одинаковые пары «слово + ответ» спрашиваются один раз и запоминаются на
время работы сервера.

## Результаты

```
http://192.168.1.14:8765/results
```

Каждый пройденный тест сохраняется в `results/` отдельным файлом и виден
на этой странице: кто, когда, сколько верно, какие слова не вспомнил и
какие ответы ждут вашей оценки.

---

## Если что-то не так

**Телефон не открывает адрес.** Оба устройства должны быть в одной сети —
не так, чтобы телефон был на мобильном интернете. В Windows при первом
запуске появится запрос брандмауэра: разрешите Python доступ к **частным**
сетям.

**Порт занят.** Запустите на другом:

```bash
set EXAM_PORT=8790
python exam-server.py
```

**Слова не подгружаются.** Сервер читает их из Firebase. Если нет
интернета, он честно скажет «offline» рядом с именем.

**Другая модель.** По умолчанию `claude-haiku-4-5-20251001` — быстрая и
дешёвая, для такой задачи её хватает. Поменять:

```bash
set EXAM_MODEL=claude-sonnet-5
```

## Файлы

```
exam-server.py     сервер: раздаёт страницу, читает Firebase,
                   спрашивает Claude, сохраняет результаты
exam.html          сам тест, который видит брат
api-key.txt        ваш ключ (не в git)
results/           пройденные тесты (не в git)
```

Слова сервер берёт прямо из `../index.html`, так что новые серии
подхватятся сами — отдельно ничего обновлять не нужно.
